# VEILWILD Reuse Map — applied to Worldbound

This document records which useful design investments from the separate Godot VEILWILD prototype were repurposed in Worldbound. It is deliberately a design-to-implementation map, not an instruction to merge two unrelated games or switch engines.

## What was not copied

The Godot-specific project setup, GDScript modules, scene tree, and third-person 3D movement are not part of the Worldbound build. Those systems serve a different game structure and would complicate the existing plain-web simulator without improving its core life-simulation loop.

The art is original procedural SVG generated by `art.js`; it is not copied from external image files. If this game later uses generated or purchased model/image assets, track each asset's source, rights, and integration status.

## How the repurposed systems connect

1. Studying the world awards `research` and permanently records field lore in `M.fieldLore`.
2. Research can be spent on `S.fieldcraft` upgrades: escape odds, herb yield, weakness matchup power, and an initial duel ward.
3. Bestiary encounters unlock bonded-beast eligibility after victory. Bonds are per-life; the discovery archive and first-victory reward persist between lives.
4. Factions and disciples augment the same engine calculations as existing techniques, elements, pills, luck, and realm progression.
5. Scene and foe illustrations communicate location and danger, but game rules remain in `engine.js`; art code does not change balance.

## Future uses that remain suggestions

- Give each Fieldcraft method an icon and a short unlock animation.
- Add optional creature track overlays and habitat hints to the SVG scenes.
- Add an expedition preparation summary showing current faction, retinue roles, bonded beasts, known foe weakness, and likely hazard.
- Add a journal comparison view for two creatures, including their region, weaknesses, and last encounter result.
- Replace individual procedural hero/foe SVGs with original finished art only after the target visual style is approved. Keep SVG fallbacks so the game works offline.
